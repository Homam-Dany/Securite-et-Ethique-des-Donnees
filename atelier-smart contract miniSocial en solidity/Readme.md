# Atelier 3 : Smart contract « Mini Réseau Social »

Smart contract Solidity permettant de publier des messages et de les consulter, déployé sur le testnet **Sepolia**.

## Fonctionnalités
- `publishPost(string _message)` : publie un message (l'auteur est `msg.sender`)
- `getPost(uint index)` : retourne le message et l'auteur
- `getTotalPosts()` : retourne le nombre total de messages

- Réseau : Sepolia
- Adresse du contrat : `0x...`
